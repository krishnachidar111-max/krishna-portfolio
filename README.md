# Krishna Chidar: Portfolio
React + Vite + Framer Motion. Run: `npm install && npm run dev`. Build: `npm run build`. Deploy: import repo in Vercel (framework: Vite).

Before publishing, edit `src/data.js`:
- `email`, `resume` (put `resume.pdf` in `/public`), `photo` (put in `/public`)
- each project's `github`, `demo`, `image` (screenshots in `/public/projects/`). Empty values show "soon" instead of fake links.
